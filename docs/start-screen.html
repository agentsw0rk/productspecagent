Product Spec Agent

Von der Produktidee zur agententauglichen Spezifikation. ProductSpecAgent fuehrt dich durch Idee, Problem, Features, Architektur, Design und Review.

Spec Agent ist bereit · v1.0

Hauptfunktionen

Ein Produktfluss, der fuer Teams und Coding Agents lesbar bleibt.

ProductSpecAgent sammelt nicht nur Text. Es erzeugt strukturierte Entscheidungen, Features, Akzeptanzkriterien, Design-Artefakte und Handoff-Dateien, die ein Team oder Coding Agent weiterverwenden kann.

01

Gefuehrter Product Wizard

Fuehrt durch Produktidee, Vision, Problem, Features, MVP, Design, Architektur, Backend, Frontend und Review.

02

Kategorieabhaengige Optionen

SaaS, Mobile App, CLI Tool, Library, Desktop App und API bekommen passende Schritte, Scopes und Technologieoptionen.

03

AI-Agent im Kontext

Der Agent reagiert auf Eingaben, erkennt offene Fragen, schlaegt Entscheidungen vor und bleibt im Projektkontext.

04

Feature-Graph

Features werden mit Frontend-/Backend-Scopes, Akzeptanzkriterien und Abhaengigkeiten als Graph gepflegt.

05

Agentic Design Workbench

Beschreibungen und Bilder werden analysiert; daraus entstehen Design-Briefing, HTML-Preview und Export-Artefakte.

06

Review, Export und Handoff

Der finale Review erzeugt Spec, Docs und ein Handoff-Paket fuer Coding Agents inklusive Projektkontext.

07

Project Cockpit und Living Sync

Nach dem Wizard werden Features, Status, Tests, Hinweise und Rueckmeldungen aus Coding-Agent-Workflows sichtbar.

08

Anpassbare Agent-Plattform

Wizard-Optionen, Prompts, Agent-Modelle und Asset Bundles koennen verwaltet und an Teams angepasst werden.

Projektarten

Der Wizard passt sich dem Produkt an.

SaaS

Mit Architektur-, Backend-, Frontend- und Design-Optionen.

Mobile App

Mit Mobile-Frameworks, App-Store-Flow und passender UI-Technik.

CLI Tool

Fokussiert auf Architektur, Distribution und Backend-nahe Umsetzung.

Library

Reduziert auf Idee, Problem, Features, MVP und finalen Review.

Desktop App

Mit lokalen Daten, Installer-Optionen und Desktop-UI-Frameworks.

API

Fokussiert auf Schnittstellen, Datenhaltung, Auth und Deployment.
